# System Video Guide

The "One connected system" section now uses a normal MP4 instead of scroll-linked WebP frames. The video is muted, loops, and plays automatically only while the section is in view.

## Active Video

- Source file: `public/omnivideos/One_connected_system_no_black_202607131711.mp4`
- Public URL: `/omnivideos/One_connected_system_no_black_202607131711.mp4`
- Poster fallback: `public/storyboards/system-start.png`

## Export Settings

- Resolution: 1920 x 1080 minimum, 3840 x 2160 preferred
- Duration: 5-8 seconds
- Frame rate: 24 or 30 fps
- Export: H.264 MP4, high bitrate, no audio
- Motion: one clean futuristic system animation, no cuts or camera shake

## Deployment Note

Because this section uses the MP4 directly, the active MP4 must be committed with the repo. Other raw Omni MP4s can stay ignored.

The old `public/sequences/system/frame-*.webp` files are no longer used.
